# Steam Big Data Platform

## Overview

This repository implements a reproducible local Big Data platform for Steam
game and review analytics.

The platform combines:

- Historical batch processing with HDFS Bronze/Silver/Gold.
- Incremental review ingestion using Kafka and Spark Structured Streaming.
- Spark SQL analytics over Gold datasets.
- MongoDB materialized views for application serving.
- Spark MLlib batch prediction with versioned training runs.

The platform separates historical and realtime processing paths:

```text
Historical Reviews
        |
        v
/steam/gold/base


Realtime Reviews
        |
        v
/steam/gold/base_incremental_v1


        |
        v

Current Gold
/steam/gold/base_current_v1

        |
        +----------------+
        |                |
        v                v

Current Analytics   MLlib Retraining

/steam/gold/        /steam/models/mllib/v1/<run_id>
analytics_current_v1
```

HDFS remains the analytical source of truth.

MongoDB provides serving/materialized views for application access.

# Data Layers

## Historical Gold

Path:

```text
/steam/gold/base
```

Canonical historical review dataset.

Grain:

```text
1 row = 1 recommendationid
```

---

## Incremental Gold

Path:

```text
/steam/gold/base_incremental_v1
```

Contains newly observed realtime reviews generated by Streaming.

---

## Current Gold

Path:

```text
/steam/gold/base_current_v1
```

Current operational analytical snapshot.

Flow:

```text
Historical Gold
        +
Incremental Gold
        |
        v

Current Gold
```

Properties:

- Same schema contract as historical Gold.
- One row per `recommendationid`.
- Used as the input source for Current Analytics and MLlib.

---

# Analytics

Historical analytics:

```text
/steam/gold/analytics/<dataset>
```

Current operational analytics:

```text
/steam/gold/analytics_current_v1/<dataset>
```

Current Refresh Scheduler updates Current Analytics whenever the Current Gold
snapshot changes.

Run:

```bash
bash scripts/run_current_refresh.sh --run-once
```

Dry run:

```bash
bash scripts/run_current_refresh.sh --run-once --dry-run
```

---

# MLlib V1

MLlib predicts:

```text
voted_up
```

Models:

- Majority baseline
- Logistic Regression
- Random Forest

ML input:

```text
/steam/gold/base_current_v1
```

MLlib is batch retraining, not online learning.

Each successful run receives a UTC `run_id`.

## Model output

Models:

```text
/steam/models/mllib/v1/<run_id>/
```

Predictions:

```text
/steam/ml/mllib/v1/test_predictions/<run_id>/
```

Evidence:

```text
evidence/ml/runs/<run_id>/
```

Each run records:

- dataset fingerprint
- input path
- train/test split
- feature contract
- parameters
- metrics
- output paths

# Current Refresh Workflow

```text
Realtime Gold
        |
        v

Current Gold Refresh

        |
        v

Current Analytics Refresh

        |
        v

Retrain Policy

        |
        +----------------+
        |                |
        v                v

     Skip ML          Retrain
```

Retraining policy:

```text
Minimum new rows: 1000

Maximum model age: 7 days
```

The scheduler prevents unnecessary retraining when the dataset has not changed
enough.
